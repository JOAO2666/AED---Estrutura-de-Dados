# Materiais de apoio

- `roteiro-segunda-prova.pdf`: roteiro de revisão preservado.
- `notas/pilha_sequencial.txt`: anotação textual do material original.
- `notas/balanceamento_arvore_binaria_incompleto.md`: pseudocódigo preservado que dependia de tipos externos e impedia a compilação isolada do exemplo AVL.
- `notas/caracterizacao_arvores_binarias_incompleta.c.txt`: rascunho conceitual original, preservado sem ser tratado como código compilável.
- `notas/arvore_binaria_sequencial_incompleta.c.txt`: rascunho original da representação sequencial.
- `notas/arvore_binaria_encadeada_incompleta.c.txt`: rascunho original da representação encadeada.
- `arquivos-originais/todos_os_arquivos.zip`: pacote legado preservado para evitar perda de conteúdo.
- `recursos-externos.md`: links de estudo que estavam documentados no README original.

Os arquivos desta pasta são referências de estudo e não participam da verificação automática de compilação.
