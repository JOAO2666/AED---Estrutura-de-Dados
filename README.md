# Curso Completo de Estrutura de Dados em C

Bem-vindo ao curso de Estrutura de Dados! Este repositório contém não apenas os códigos-fonte das implementações, mas também um guia de estudos completo para você aprender de forma estruturada, combinando videoaulas, teoria em PDFs e a prática com o código.

O material está organizado em módulos sequenciais, do básico ao avançado.

---

## 📚 Módulos do Curso

### Módulo 1: Introdução a Estruturas de Dados
**Descrição:** Este módulo inicial apresenta os conceitos fundamentais de tipos de dados, a importância da análise de algoritmos e as primeiras noções sobre alocação de memória, que são a base para todos os tópicos seguintes.
- **Ordem de estudo recomendada:** Comece pelo vídeo de introdução para ter uma visão geral, depois leia o PDF sobre Tipos Abstratos de Dados (TAD) para a base teórica e, em seguida, o material sobre Análise de Algoritmos.

- **Recursos:**
  - 🎥 **Vídeo:** [Introdução a Estruturas de Dados](https://www.youtube.com/watch?v=A_zL-8rhSbc&list=PLMx6FZj7-18bH9UWzsY31zf45eHn0I_dO&index=1)
  - 📄 **PDF 1:** [Tipos Abstratos de Dados (TAD)](https://docentes.univasf.edu.br/marcelo.linder/aedc2_1_tad.pdf)
  - 📄 **PDF 2:** [Análise de Algoritmos](https://docentes.univasf.edu.br/marcelo.linder/aedc2_2_analise.pdf)

### Módulo 2: Listas Sequenciais
**Descrição:** Introdução ao conceito de listas e sua primeira implementação utilizando alocação sequencial (vetores). Você aprenderá as operações básicas como inserção, remoção e busca.
- **Ordem de estudo recomendada:** Assista à videoaula para entender a lógica e veja o código no GitHub para ver a implementação prática. O PDF de listas serve como um excelente complemento teórico.

- **Recursos:**
  - 🎥 **Vídeo:** [Listas - Alocação Sequencial](https://www.youtube.com/watch?v=u-S-t91-G4s&list=PLMx6FZj7-18bH9UWzsY31zf45eHn0I_dO&index=2)
  - 💻 **Código no GitHub:** [Lista_Sequencial.c](https://github.com/JOAO2666/AED---Estrutura-de-Dados/blob/main/Lista_Sequencial.c)
  - 📄 **PDF:** [Listas (Sequencial e Encadeada)](https://docentes.univasf.edu.br/marcelo.linder/aedc2_3_listas.pdf)

### Módulo 3: Pilhas (Stacks)
**Descrição:** Este módulo aborda as pilhas, uma estrutura de dados do tipo LIFO (Last-In, First-Out). Você verá a implementação tanto com alocação sequencial quanto encadeada, além de um exemplo prático de sua aplicação.
- **Ordem de estudo recomendada:** Inicie com os vídeos, começando pela alocação sequencial e depois a encadeada. Explore os códigos correspondentes no GitHub. O exemplo de aplicação (conversão de expressões) é ótimo para consolidar o conhecimento.

    - [Pilhas - Alocação Encadeada](https://www.youtube.com/watch?v=r2K4a-t7bYg&list=PLMx6FZj7-18bH9UWzsY31zf45eHn0I_dO&index=4)

    - [Pilhas_Alocacao_Sequencial.c](https://github.com/JOAO2666/AED---Estrutura-de-Dados/blob/main/Pilhas_Alocacao_Sequencial.c)

### Módulo 4: Filas (Queues)
**Descrição:** Aqui você aprenderá sobre filas, uma estrutura de dados do tipo FIFO (First-In, First-Out). O módulo cobre a implementação com alocação encadeada e um exemplo de aplicação em ordenação.
- **Ordem de estudo recomendada:** Assista ao vídeo sobre filas e, em seguida, explore os códigos no GitHub para ver as implementações. O PDF teórico ajudará a solidificar os conceitos.
