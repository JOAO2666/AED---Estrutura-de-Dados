# Pilhas

Pilhas seguem a política LIFO: o último elemento inserido é o primeiro removido.

- `pilha_sequencial.c`: armazenamento em vetor.
- `pilha_encadeada.c`: armazenamento dinâmico com nós.
- `conversao_expressoes.c`: aplicação de pilhas na conversão e avaliação de expressões.

Observe especialmente as operações `push`, `pop` e consulta ao topo.
