# Listas

Listas armazenam uma sequência de elementos e permitem estudar diferentes custos de acesso, inserção e remoção.

- `lista_sequencial.c`: implementação baseada em vetor, com capacidade fixa.
- `lista_simples_encadeada.c`: exemplo executável e comentado de nós ligados por ponteiros.
- `listas_variacoes.c`: menu comparativo com lista sequencial, simplesmente encadeada, circular, duplamente encadeada e circular dupla.

Comece pela lista sequencial e compare o deslocamento de elementos com a atualização de ponteiros nas versões encadeadas.
